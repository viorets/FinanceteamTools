Mark up a PDF

Add text, highlights, lines, arrows and drawings, then download a marked copy. The original file is not changed.

PDF up to 12 MB · or drop it here · drafts stay on this device

Text box: select letters and press B, I, U, S or the highlighter (Ctrl+B / I / U, Ctrl+Shift+X). Typing --> gives → and ==> gives ➜. Hold Shift for straight lines and squares. Zoom with Ctrl + mouse wheel, a pinch, or − / +.

Edit an Excel file

Cells, formulas (calculated live), formatting, rows and columns, sort and filter. Download the workbook or one sheet as CSV, TSV, text, JSON or HTML.

Excel workbook (.xlsx) · or drop it here · charts, images and pivot tables are not kept

Click a cell and type (F2 or double-click edits it). Drag or Shift+click to select a range; copy and paste work with Excel. Drag the small square to fill a series. The Name Box jumps to an address; sheets are tabs at the bottom.

Edit a Word file

Edit the page as in Word: fonts, colours, lists, styles, text boxes and shapes. Download it as .docx, or export PDF, text, Markdown or HTML.

Word document (.docx) · or drop it here · headers and footers are not shown

Enter starts a new paragraph. Right-click a style (or Modify…) to change it; ticked styles are remembered in this browser. Find & export finds and replaces text. Insert draws text boxes, lines, arrows, rectangles and pen strokes.
